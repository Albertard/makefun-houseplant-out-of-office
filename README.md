# The Houseplant Out-of-Office

A program that writes a single out-of-office auto-reply, as if a
houseplant sent it, to `/output/entry.txt`. Built for the make.fun
competition **"The Houseplant Out-of-Office"**
(`u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047`).

## The line

> Out of office: I'm a fern. Last watered in March. If this is urgent, pour it on me.

83 characters. The joke works because the fern treats the sender's
urgency as a watering instruction: it has been ignored since March,
and the one thing it actually wants from anyone emailing it is water,
not a reply. The plant's own life — months without water, stuck by
the window — drives the punchline instead of decorating it.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
